# Show Password

A simple Show Password project that allows users to toggle password visibility while entering their password.

## Features
- Toggle password visibility.
- Switch between hidden and visible password input.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the `showpassword.html` file in your browser.
2. Enter a password in the input field.
3. Click the visibility control to show or hide the password.
